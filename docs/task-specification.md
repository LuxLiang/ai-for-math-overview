# Task Specification: Evidence for Mathematical Contribution

[Overview](../README.md) · [Overlap audit](overlap-audit.md) · [Evaluation design](research-gaps.md)

这是一份拟议任务规范，目的是把“这篇论文新在哪里”转成可以逐项复核的研究问题。下列诊断例子均为构造示例，不是真实论文的归因结果，也不是已有专家标注集。

## 1. Fix the input and the reference frame

一次分析至少指定论文版本、主定理、领域和允许使用的标准背景，以及分析时间点。前作证据应有实际读取版本与具体位置；更早发表并不自动意味着当前作者或模型实际使用过它。

区分三个时间：原始主张首次可核实的公开时间、当前文档版本的时间，以及分析时可以检索到的材料。历史优先权和模型生成过程的因果归因分别记录。

## 2. Represent an inference, not just adjacent sentences

将推断写作 **(P₁, …, Pₖ; C) → Q**：P 是共同使用的前提，C 是领域、局部假设及已允许的背景，Q 是结论。可以用一个推断节点连接所有前提与结论；联合前提也可用超边表示。相关表示已有先例，见[重叠分析](overlap-audit.md)。

- A 和 B 共同推出 C，不表示 A 单独或 B 单独推出 C。
- 若有两条替代证明，应保留两个可选的推断集合，不把它们合并为一组必需前提。
- 引用支持某个结论、该证明实际使用一个来源、某个来源在历史上最早提出内容，是不同关系。
- 依赖某条边表示它在当前论证中的作用，不证明所有可能证明都必须经过这条边。

## 3. Use separate annotation axes

“沿用 / routine / 新连接 / 证明缺口”可以出现在同一个论证片段里，不作为一个互斥分类题。

| 维度 | 应记录什么 | 未决时如何处理 |
| --- | --- | --- |
| 来源对应 | 与哪个前作的结果、技巧、路线或片段对应，给出两侧位置 | 记为尚无已确认对应；不转为原创 |
| 适用条件 | 对象、量词、假设、参数范围和结论是否匹配 | 缺上下文则不作确定的涵盖判断 |
| 改造义务 | 哪个旧条件不能直接满足，新增了什么构造或引理 | 将待完成义务单列，不提前认定已完成创新 |
| routine | 给定背景与粒度，能否写出标准的补全推导 | 没写出补全或搜索超时，保持未知 |
| 论证状态 | 已支持、条件性、存在已确认缺陷、未核对 | 引用遗漏或细节省略本身不自动使证明错误 |
| 结果与方法新颖性 | 分别比较命题、证明路线、场景与反例 | 暂定判断带检索范围与专家复核状态 |
| 主证明中的作用 | 支撑哪些关键结论，是否有当前已知替代路径 | 不用节点数量或脚本长度分配贡献百分比 |
| 过程贡献 | 人、模型、工具与文献实际做了什么 | 没有操作记录不补造生成历史 |

例如：一段论证可以“复用前作 A 的方法，提出一个针对新假设的改造，但改造所需的估计尚未证明”。来源、方法差异和未完成状态都应保留。

## 4. Require a witness for routine

routine 的正面判断应附一个**补全依据**：在给定背景下，列出使用的标准事实、替换的变量或对象、条件检查，以及足以解释推断的推导。它可以由专家确认，也可在已忠实形式化的局部任务中提供可检查证明。

“模型很快写出来”“tactic 很快成功”“没有新术语”都不能单独代替这个依据。tactic 也可能直接调用了待分析的目标定理或晚于时间点的结果，必须检查允许的上下文。

这个要求是本规范的操作选择，尚待验证是否符合领域专家对 routine 的使用方式；不是声称提出了全新的数学概念。

## 5. Distinguish common failure cases

| 构造诊断 | 合理处理 | 应避免的错误 |
| --- | --- | --- |
| 前作证明“连续且定义域紧时取到最大值”；当前只有连续 | 指出紧性缺失，并检验替代条件；f(x)=x 在 ℝ 上即可提示条件问题 | 因关键词和结论相似就认定前作已覆盖 |
| 同一个命题只改变量名、段落顺序或拆分步数 | 保持命题对应和主要贡献判断稳定 | 将不同措辞或更多步骤当作新增数学内容 |
| P 与 Q 是数学内容不同、且在当前理论里均可证的真命题 | 比较对象、假设和结论角色 | 用整句 P ↔ Q 可证就认定同一结果 |
| 文献结果适用，但需要一个非显然的新对象构造 | 记录既有结果与新构造义务，核查构造是否完成 | 因结论是旧定理的应用就一概标为 routine |
| 搜索没命中、全文不可得或验证超时 | 保留未知、检索范围和失败原因 | 把无法确认覆盖当作证实原创 |
| 一条历史上已知的路线中出现未完成的估计 | 同时保留已知来源与缺失义务 | 强迫在“沿用”和“证明缺口”之间二选一 |
| 一个反例有效，但存在等价的更早构造 | 分别记录反例有效性、构造对应和历史先例 | 将“找到反例”直接等同于新反例贡献 |

这些例子用于审查任务定义。模型在这些诊断上的表现尚未测量，不能将它们报告为系统成果。

## 6. Build the smallest useful expert study

先选一个有专家与可获取前作支持的领域，冻结少量真实论文及其关键推断。由独立专家建立来源对应、条件检查、routine 补全依据与争议记录，再比较自动方法。

对照至少包括原文直接总结、陈述检索与条件核对、图辅助检索、来源溯源报告，以及加入独立疑点验证的版本。使用相同材料和预算；覆盖正确引用、未引用、实质改造、标准推导和未决情形。

| 评价对象 | 可核对的问题 |
| --- | --- |
| 数学来源对应 | 来源位置与关系是否正确，而非只返回相关论文 |
| 条件与范围 | 是否发现不适用的假设、量词或对象差异 |
| routine 补全 | 补全是否有效、是否使用允许的背景，是否获专家认可 |
| 贡献判断 | 是否把未知、错误、格式变化或已知内容误报为新贡献 |
| 弃判与覆盖 | 哪些关键推断有充分证据，哪些仍需专家审阅 |
| 稳健性 | 改名、改写、拆分/合并步骤后，判断是否保持一致 |
| 专家成本 | 验证一条有效发现需要多少时间和原始材料 |

优先完成真实案例与独立复核，再决定训练目标和自动化程度。该顺序避免用一个看似完整的贡献图掩盖未解决的数学判断。
