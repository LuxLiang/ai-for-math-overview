# Research Gaps and Evaluation

[Overview](../README.md) · [Task specification](task-specification.md) · [Overlap audit](overlap-audit.md) · [Related work](related-work.md) · [Contribution attribution](contribution-attribution.md)

工作假设：贡献归因的主要困难在于把论文中的数学内容、先前文献和专家判断连接起来。以下是基于本索引所覆盖工作的研究问题，不能视为“尚无任何研究”的断言。

## Gap map

| 问题 | 已有基础 | 待检验的技术难点 | 可观察的结果 |
| --- | --- | --- | --- |
| 证明结构 | Blueprint、候选陈述图与形式化依赖 | 自动候选图能否覆盖和忠实表示主证明的关键连接 | 专家标注的主张和关键依赖召回率 |
| 跨论文对齐 | 陈述检索、语义匹配、引用恢复与局部内容对应 | 符号改写、假设变化、间接引用及不同表述 | 对应证据的精确率和困难负例识别 |
| 关键连接 | 证明搜索与错误检查 | 新增义务是已知引理、常规推导还是实质创新 | 候选连接的专家一致率与误报 |
| routine 判断 | 标准库、自动 tactic、领域知识 | 领域和粒度不同导致标签漂移 | 明确先验下的专家一致性与弃判情况 |
| 整体贡献 | 局部溯源报告 | 防止用旧步骤占比掩盖关键新连接 | 研究者能否从报告正确定位数学增量 |
| 专家成本 | 候选优先级与审阅筛选 | 错误指控、漏掉贡献与审阅时间的权衡 | 给定时间预算下确认的有效发现 |
| 因果贡献 | 日志、受控检索条件 | 训练知识不可见，文献相关性不等于因果作用 | 限定条件下的消融效果，不泛称“独立原创” |

## A minimal empirical study

先开展有边界的案例研究，再决定是否需要训练模型。下面是建议的实验设计，尚未运行。

### Corpus

选择一个有可访问前作、可管理证明长度和领域专家支持的子领域。样本应同时包含明确复用、充分引用、实质改造、常规组合及专家认定的新连接。不要只选已发现问题的手稿；否则无法估计误报和贡献识别能力。

冻结论文版本、文献可用时间和可访问文件。math-lineage 报告可提供种子案例，但须独立核对后才能进入专家标注集。保留真正的新连接与“相似但不适用”的前作作为困难对照。

### Baselines and ablations

| 对照 | 回答的问题 |
| --- | --- |
| 直接整篇判断 | 分解是否优于让模型直接总结贡献 |
| BM25 / NaturalProofs 类前提检索 + 局部对应 | 相对简单检索，复杂检索带来什么增益 |
| TheoremSearch / Matlas 陈述检索，及 TheoremGraph 图扩展 | 语料与结构对未引用前作找回的帮助；统一查询与候选预算 |
| 按主张检索 + 条件核对 | 显式数学结构是否减少错误对应 |
| 已知引用恢复 / 未引用技巧发现分开评价 | 防止仅通过恢复原文引用就宣称贡献归因成功 |
| 去掉独立验证阶段 | 提议与验证分离是否降低幻觉归因 |
| 仅原文参考文献 / 扩展公开检索 | 检索边界对结论的影响；不解释为清除预训练知识 |
| 数学工具提取/来源图近邻与本方法使用相同材料 | 测量是否减少错误归因、未支持的新颖性判断与关键遗漏 |
| 有 / 无主证明依赖 | 图结构是否帮助区分关键贡献与外围技术细节 |

### Annotation

请领域专家分别标注来源关系、条件是否适用、改造义务、主证明中的作用、routine 补全依据和论证状态；这些维度不互斥。允许弃判，记录争议理由；展示模型建议前先获得独立判断，降低锚定效应。多位专家之间的分歧是研究对象的一部分。

### Metrics

- **对应精确率**：已确认对应中，数学内容和适用条件都正确的比例。
- **基准内召回率**：对专家建立的已知对应集能找回多少；不宣称对全部数学文献的全局召回率。
- **新颖性误报**：将已知结果、普通推导或证明缺口错误标为新贡献的情况。
- **贡献漏报**：将专家确认的新连接误归为沿用或 routine 的情况。
- **覆盖与弃判**：多少关键主张已审阅，多少仍缺全文、证据或专家判断。
- **结构稳健性**：变量改名、等价改写和拆分/合并步骤不应凭空改变贡献判断；联合前提与替代路线单独检查。
- **专家成本**：每条确认发现的审阅时间、需读的来源数及证据充分程度。

引用数量、步骤数量、文本相似度与 tactic 长度可以作为诊断变量；它们都不能直接充当贡献比例。

## First deliverable

先按[任务规范](task-specification.md)构建经专家核对的关键推断案例集，再比较现有提取、检索、图辅助与局部验证方法。需要测量每个维度的证据质量，而非只完成一张贡献图。优先验证“能否可靠定位数学增量”，再考虑自动化打分和大规模运行。
