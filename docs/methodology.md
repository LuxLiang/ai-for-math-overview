# 收录与核对方法

[返回主页](../README.md)

## 范围与来源

覆盖 AI 辅助数学的证明、自动形式化、几何、自然语言推理、数学发现和评测。通用训练框架仅在有直接数学研究工作流时选入；当前首版不系统覆盖 PDE、数值分析、所有符号计算系统或全部历史证明助手。

优先选择项目维护者的上游仓库、作者提交的 arXiv 页面、期刊论文和官方技术文章。第三方实现按实际来源标注。仓库迁移后使用 GitHub 返回的当前规范地址；同一项目的不同版本可以独立收录，但避免重复记录迁移前后的地址。

2026-10-25 首版通过 GitHub API 核对仓库存在性、当前地址、归档状态与仓库级许可元数据；通过上游 README、arXiv 元数据、期刊和官方文章核对条目。没有逐个安装、训练或复现这些系统，因此“已核对”表示来源核对，并非运行验证。

## 开放范围

- **代码 / 模型 / 数据**：用于描述可获取的资源类型；不等价于完整训练流程已经开放。
- **部分组件**：例如 AlphaGeometry 2 仓库公开 DDAR 核心，不能据此声称完整系统开放。
- **研究材料**：例如发现的算法、手稿、实验输出和验证代码，需逐项检查。
- **第三方代码**：例如 OpenEvolve，不视为原始 AlphaEvolve 系统的官方实现。

`license` 是 GitHub 返回的仓库级 SPDX 元数据快照；`NOASSERTION` 表示没有得到明确标识。代码、权重和数据的使用应查看相应文件的实际许可。

## 比较结果时记录什么

| 维度 | 至少记录 |
| --- | --- |
| 任务 | 自然语言答案、完整论证、形式化证明、自动形式化或构造搜索 |
| 数据 | 基准名称、提交版本、训练/验证/测试切分、潜在污染 |
| 推理预算 | 采样数、pass@k 定义、token、搜索节点、超时与总成本 |
| 系统条件 | 模型版本、Lean/Mathlib 版本、提示、可用工具与外部检索 |
| 人工参与 | 手工形式化、辅助引理、修改提示、筛选输出等 |
| 验证 | 最终答案比较、执行测试、内核检查、人工审阅或同行评审 |

不同预算与不同基准版本的数值不能直接当作统一排行榜。本文不维护混合口径的 SOTA 排名。

## 数学正确性与形式化忠实性

Lean 检查通过后，还需要检查目标陈述与原问题是否一致、公理依赖是否合理，以及是否使用 `sorry`、`admit` 或其他绕过完整证明的机制。真实项目可能还需要 statement comparator、独立构建或额外审计。

自然语言验证器与最终答案比较工具提供的保证不同于证明内核。对算法和构造，评价器正确、数值精度及适用范围也需要单独说明。研究手稿是否经过同行评审、是否有对应形式化证明，应逐篇确认。

## 维护频率

此版本是人工核对的静态快照，没有开启定时自动更新。后续更新应刷新条目的 `checked_on`，并说明是否实际复现。网页可访问不保证资源持续可用，官方历史文章也不保证其中的实验 API 仍在服务。
